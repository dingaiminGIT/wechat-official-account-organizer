# 公众号整理 · Mac 本机内测版

双击 `dist/公众号整理.app` 使用。应用内置网页服务、Node.js 与固定版本 WMPFDebugger，运行时不需要终端或开发环境。当前为 ad-hoc 签名的本机内测版本，未完成对外签名、公证及其他电脑验证。

## 使用流程

1. 登录微信并打开公众号页面；启动应用，查看兼容性检查。
2. 点击「开始连接」后，在微信左侧进入小程序列表，再点开任意一个小程序的内容页面（只打开列表不够）。应用会短时间自动检测连接；已经打开但无法连接时，关闭该小程序再重新打开。使用期间保留微信和小程序窗口，可切回本应用。超时后点击「开始连接」重试。当前采用手动引导，不自动点击微信，也不要求辅助功能权限；连接不会执行取关。
3. 选择账号，维护白名单，生成清单并点击开始。执行逐个进行，完成复核后立即处理下一个账号。每项检查兼容环境，操作器在操作前后核对本机会话；操作后立即查询状态，仅状态尚未更新时短暂等待再查。
4. 在“取关记录 / 恢复关注”查看最近 30 天的记录，点击“重新关注”并确认后恢复。默认将恢复的账号加入白名单。记录到期后在应用启动或使用时自动清理，白名单继续保留。
5. 退出应用会停止后续队列，等待当前账号完成复核，再关闭应用拥有的调试服务。不会退出微信。

## 支持范围与升级策略

当前只启用已经验证的组合：Apple Silicon、macOS 26.6.2、微信 4.1.11、WMPF build 269136，以及精确的微信组件 SHA-256。具体配置见 `compatibility.json`。

WMPFDebugger 固定到 `1d9f6e03a24dcd39baa223e25a883a85b84bd303`，不在用户设备自动更新或下载代码。上游未适配的新微信版本直接暂停接入，保留本机记录，等待我们验证后的应用更新；不自动降级微信或关闭系统保护。新版本不只凭上游“支持”声明开放，需要验证列表、身份绑定、取关回执、结果复核及故障恢复。

## 账号与环境保护

- 不读取聊天数据库内容。通过微信进程当前打开的数据目录识别本机账号，用哈希作为隔离目录；目录不唯一时拒绝执行。
- 清单绑定账号及微信进程会话；切换账号、重启微信或旧页面发来的请求均不能直接执行旧清单。白名单、选择和日志按账号分开。
- 服务每项执行前验证环境；执行器在真实取关前再次检查会话和白名单。遇到不确定结果暂停；恢复先查询，跳过已经未关注项。
- CDP 控制连接只监听本机，使用每次启动生成的随机令牌并拒绝网页 Origin。原生小程序调试入口受上游协议限制，仍为本机端口。
- 数据位于 `~/Library/Application Support/com.baiya.WeChatOrganizer`，目录/文件使用用户私有权限；安装包不包含账号列表、白名单、令牌或本机微信备份。
- 环境准备/恢复须用户在应用明确选择并接受系统管理员授权，且先退出微信。恢复前校验版本与文件指纹；升级后的文件、损坏备份或未知文件不覆盖。
- 这些机制降低误操作和兼容性风险，不保证平台账号零风险。当前仍使用调试接入和辅助程序签名调整。

## 构建与验证

开发时需要 Swift、Python 3.11+、Node 22+ 与固定依赖；用户运行已打包应用不需要这些开发工具。

```sh
python3 -m venv .build-env
.build-env/bin/pip install pyinstaller==6.22.2
./script/build_and_run.sh --verify
python3 -m unittest discover -s . -p 'test_*.py'
```

脚本生成真实 `.app` 并通过 Launch Services 启动。应用内 `Resources/Source` 保存当前代码及 WMPFDebugger 源码、版本与许可声明。WMPFDebugger 原始目录当前在相邻研究目录，构建脚本会使用该固定源码，不从网络获取最新版本。
